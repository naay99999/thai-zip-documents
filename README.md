# thai-zip-documents

Documentation website for [`thaizip`](https://www.npmjs.com/package/thaizip) and [`react-thaizip`](https://www.npmjs.com/package/react-thaizip), live at **https://thai-zip.vercel.app** (Thai) and **https://thai-zip.vercel.app/en/docs** (English).

Both packages are installed from npm, so the live demos and install steps always match a published release.

```bash
npm install
npm run dev    # http://localhost:3000
npm test
npm run build
```

Package source lives in [naay99999/thai-zip](https://github.com/naay99999/thai-zip) and [naay99999/react-thai-zip](https://github.com/naay99999/react-thai-zip).
